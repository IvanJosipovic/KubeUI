# Crossplane icons

Official CNCF Crossplane icon SVGs, copied unmodified from the
[CNCF artwork repository](https://github.com/cncf/artwork/tree/main/projects/crossplane/icon):

- `crossplane-light.svg` is the color icon used in the light theme.
  Source: [color SVG](https://github.com/cncf/artwork/blob/main/projects/crossplane/icon/color/crossplane-icon-color.svg)
- `crossplane-dark.svg` is the white icon used in the dark theme.
  Source: [white SVG](https://github.com/cncf/artwork/blob/main/projects/crossplane/icon/white/crossplane-icon-white.svg)

The icon artwork is provided under the
[CNCF artwork license](https://github.com/cncf/artwork/blob/main/LICENSE).
The SVGs are icon-only and use a square viewport; preserve the official geometry and colors.
