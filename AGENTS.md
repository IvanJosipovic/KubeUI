# KubeUI agent guidance

The canonical agent guidance, architecture, and skills are in the companion
KubeUI-eng repository: https://github.com/IvanJosipovic/KubeUI-eng.

Before working, read its root `AGENTS.md` and the applicable scoped guides.

available, ask for access rather than proceeding without its guidance.
